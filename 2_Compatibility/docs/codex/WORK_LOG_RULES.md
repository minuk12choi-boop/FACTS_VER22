# Work Log / feedback_log 규칙

## 위치

```text
feedback_log/
```

## 파일명

```text
YYYYMMDD_HHMMSS_<task_slug>.md
```

## 포함 내용

- 작업 목적
- 수정 파일
- 삭제 파일
- 신규 파일
- migration 파일
- 검증 명령과 결과
- 실패 명령과 사유
- 미완료/부분완료 항목
- 사용자 수동 테스트 항목

## 요청사항 상태표

모든 보고서에 포함:

```text
번호 | 요청사항 | 상태(완료/부분완료/미완료) | 근거 | 남은 확인
```

## skip 금지

요청사항을 조용히 넘기면 실패입니다. 못 하면 못 한 이유를 최상단에 씁니다.
