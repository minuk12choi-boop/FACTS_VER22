# FACTS 프로젝트 고정 규칙

## 서비스 성격

FACTS는 사내에서 실제 사용 중인 Django 기반 WEB입니다. 유지보수성 개선보다 더 중요한 것은 기존 기능 보존입니다.

## 절대 금지

- 기존 기능 삭제
- 기존 URL/URL name 변경
- 기존 권한/SSO 흐름 변경
- 기존 계산 결과 의미 변경
- 운영 DB 직접 migration 실행
- 운영 `config/settings.py` 불필요 수정
- 백업 파일 생성
- 요청사항 skip
- 검증 없이 “완료” 보고

## 요청사항 처리 방식

모든 요청은 번호별로 완료/부분완료/미완료 상태를 보고합니다.

보고서 최상단 형식:

```text
미완료 / 차단 사유 / 필요 확인사항
- [미완료] 항목명: 사유, 필요한 확인사항
- [부분완료] 항목명: 구현 범위, 남은 검증
```

완료하지 못한 항목이 하나라도 있으면 최상단에 먼저 씁니다.

## 사용자의 사내 검증 방식

사용자는 사내 PC에서 `git pull`을 기본으로 사용하지 않습니다. Codex 결과물을 직접 받아 적용하거나 별도 방식으로 반영합니다. 따라서 수동 검증 안내에 `git pull`을 기본 명령으로 넣지 않습니다.

## Windows 기준

명령어와 경로 설명은 Windows PowerShell / VS Code 터미널 기준으로 작성합니다.
