# FACTS Codex Harness 문서

이 디렉터리는 Codex가 FACTS 프로젝트를 안정적으로 수정하기 위한 하네스입니다.

AGENTS.md는 목차입니다. 세부 규칙은 이 디렉터리의 목적별 문서를 읽습니다.

## 적용 방법

이 ZIP을 FACTS 저장소 루트에 압축 해제합니다.

예상 구조:

```text
AGENTS.md
docs/codex/*.md
docs/codex/exec-plans/active/.gitkeep
docs/codex/exec-plans/completed/.gitkeep
feedback_log/.gitkeep
```

Codex 작업 프롬프트에는 필요한 문서만 참조하도록 지시합니다.
